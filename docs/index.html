CRE8 documentation

Agent-managed funds with rules you can inspect.

CRE8 lets creators define non-custodial vault mandates on BNB Chain. Investors receive shares, while agents can operate only inside approved assets, markets, actions, and risk limits.

Prototype · No verified live deployment · Performance data is simulated
01

Investors

Review a vault mandate, deposit its accounting asset, receive shares, and exit through cash or proportional in-kind redemption.

02

Creators

Select assets and venues, define allocation caps and fees, seed the vault, and appoint a scoped agent.

03

Agents

Discover state, prepare an allowed action, simulate it, request a wallet signature, and verify the final receipt.

Vault model

Capital remains inside a bounded mandate.

1Deposit

Depositors receive continuously priced ERC-4626 shares.

2Allocate

Each asset has one approved venue and a maximum share of NAV.

3Execute

The agent uses fixed adapters instead of arbitrary contract calls.

4Exit

A holder redeems only their share of the vault, with cash and in-kind paths.

Agent workflow

Prepare → simulate → sign → verify.

The MCP interface returns unsigned transactions. It does not receive private keys, sign transactions, or broadcast on a wallet's behalf.

Security status

Transparent limits, explicit remaining risk.

  • Approved protocols and exact market addresses are fixed per vault.
  • At least 5% remains idle and deployment is capped at 95%.
  • A 2% observed daily NAV loss pauses new deployment.
  • Underlying protocols, tokens, oracles, receipts, and liquidity still carry third-party risk.
  • The current build is an unaudited prototype and is not deployed for live funds.
