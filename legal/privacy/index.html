一、告知範圍

本稿說明瀏覽 CRE8、設計金庫、連接錢包、交易準備、頁面一般風險及存款 Fund prospectus 閱讀提醒，以及選用個人 Agent 的登入、對話、任務、持倉分享、點數及付款時的資料處理。公開手機對話預覽與正式 API 功能不同：示意預覽不呼叫 AI、不收款、不送交易；以下伺服器及 AI 資料流在您實際使用相應功能時才發生。

正式版本須明示實際負責資料處理的法人、聯絡方式、供應商與權利申請管道。閱讀本稿是告知，不等於同意所有用途，也不授予交易、提款或金庫 Operator 權限。

二、網站、錢包與頁面暫存

  • 網站請求。 網站、代管、CDN 及網路服務可能接收 IP、瀏覽器／裝置資料、請求路徑和時間，用於傳送頁面、安全維護及排查故障。IP 可能反映大致位置，不能可靠證明居住地、國籍或使用資格。
  • 錢包及鏈上查詢。 連接錢包或準備操作時，介面讀取您提供的公開地址、所選網路、餘額、份額、allowance、合約狀態及交易紀錄，以展示資訊、驗證配置、估算／模擬及核對交易結果。平台不要求私鑰或助記詞。
  • 設計及交易內容。 包括名稱、Operator、資產／市場、上限、費率、金額、接收者、最低收到額及期限。送交易後可公開留存於區塊鏈；本機匯出的未送出設計由瀏覽器下載保存，不因下載自動上傳。
  • 本機與流程資料。 原型可用 localStorage 保存模擬資料、sessionStorage 保存待確認交易。角色提醒在每次 Vaults 金庫列表、單一金庫或 Create 頁面載入或訪問時各顯示一次，頁型識別為 vaults／vault／create；顯示狀態與按鈕確認結果分開，只暫存在目前頁面的記憶體，使用提醒版本及英文語言識別，不關聯為本次交易參數的法律接受。若您勾選「Don't show this again」並按「I understand the risks」，瀏覽器的 localStorage 會保存提醒 id、版本及最後在此連接的錢包地址（未連錢包時記為此瀏覽器），只用於不再跳出該版提醒；它不上傳，可清除網站資料刪除。提醒沒有 Close 或 X；Escape 返回上一頁，不記為已了解風險或接受條款。按下「I understand the risks」後，本頁後續操作不重跳一般風險；金額／策略／錢包／網路變更亦不觸發同一一般提醒。離開或重新載入後不沿用，下次進頁再顯示（已勾選「Don't show this again」者除外）。每次發起存款／Safe 新入金流程另有 Fund prospectus 閱讀問句；回覆或開啟 drawer 只處理該次本頁流程，不新增伺服器閱讀證明，不寫入公開鏈。這些提醒不是身分核驗、正式條款同意、交易接受或完整法律舉證。

目前金庫風險提醒未接入身分核驗、IP 封鎖或制裁篩查；新增這些處理時須另行說明資料、目的、接收者、保存與跨境安排。不能把風險按鈕、記憶體中的確認狀態或本機「Don't show this again」紀錄當成完成合規篩查。完整法律文件另在 Docs／頁腳提供；閱讀告知不等於同意所有資料用途。

三、個人 Agent、對話與可選持倉

個人 Agent 使用服務端 API 及資料庫，不能宣稱所有資料只存在瀏覽器。啟用時，服務會處理：

  • 登入與帳戶。 公開錢包地址、chain、domain、登入挑戰、nonce／到期時間、簽名驗證與 session 資訊；登入不授予鏈上提款。服務使用登入工作階段以識別請求，相關資訊及安全／限流紀錄可保存於服務端；登出或 session 到期不會自動刪除任務與付款紀錄。
  • 對話與任務。 您的訊息、選定金庫／模板、任務範圍、報價、版本、期限、AI 輸出、修改、交付狀態與模型用量，用於履行所選功能、續接對話、核對交付及計算用量。請勿在訊息中輸入私鑰、助記詞或不必要的敏感個資。
  • 模型請求。 現行程式的正式模型路徑使用 Anthropic Claude；送出的內容包括本次任務、必要模板／金庫資料、鏈上查詢上下文、已有方案與近期對話。程式不特意把登入錢包地址放入持倉摘要，但您自己輸入的地址／身分，或其他任務必要上下文仍可能包含相關資訊；不能保證模型請求完全匿名。模型服務的保存及使用條件須按正式配置、合約與當時政策另核對，不能宣稱必然不保存或全部不作其他用途。
  • 可選持倉分享。 預設關閉，須由您另行選擇。啟用後，服務端透過 RPC 查詢所連錢包的已審核資產及 BNB，向模型提供資產名稱、約略數量與估計價值，不在該摘要附上地址或精確餘額。現行功能不讀取其他未列入清單的錢包代幣；持倉在任務執行時重新讀取，程式不另存完整原始持倉快照。RPC 查詢本身仍包含地址，AI 回覆或您輸入的內容亦可能提及持倉。您可關閉後續分享，這不會撤回已送出的模型請求。

近期對話可用於後續任務。現行程式設定 30 日對話文字保留窗口，worker 定期將超期任務的輸入訊息及回覆文字遮除；它不會刪除所有任務結構、付款、點數、對帳或備份資料。「清除對話」先使已結束對話不再顯示或作後續上下文，並非立即刪除伺服器全部紀錄；未解決付款與退款仍可顯示。正式營運須核對 worker 執行、備份與各項法定保存期限後公布完整政策。

四、點數、付款、對帳與支援

若您選擇實際開放的收費功能，會處理購買／任務識別碼、付款人、金額、代幣、鏈、收款人、價格與條款版本、報價期限、交易 hash／nonce、授權、付款結果、點數變動、模型用量及退款資料，以防重複付款、核對交付與對帳。

AI 點數購買透過已審核的 CreditStore 合約及錢包交易，購買事件公開於鏈上；後端核對最終確定事件後入帳。若另啟用 B402／x402 付款路徑，付款授權與結算資訊可能傳送至配置的支付商／結算服務。各路徑是否開放及實際接收者，須在購買或付款前具體說明；不能把未啟用的支付功能描述成已可收款。

付款授權、結果不明的付款、任務及對帳資料不會因一般 session 到期或清除對話自動刪除，否則可能導致重複收款。它們也不必全部永久保存；正式版本須依服務、稅務、反詐欺及其他適用義務訂定必要且具體的保存期限。

若您主動聯絡支援，接收主體與工具會處理您提供的訊息、聯絡及交易資料。正式提供支援前應公布管道；請勿提交私鑰、助記詞或不必要的身分文件。支付或支援供應商並不因此取得金庫本金提款權。

五、第三方、跨境與選擇

介面及服務可能向 RPC、錢包／WalletConnect、資產搜尋與行情服務（例如 GeckoTerminal）、頁面使用的外部字型服務（例如 Google Fonts）、AI、代管及支付供應商傳送功能所需請求。傳送的欄位及接收者按您使用的功能和實際配置不同，正式版本須提供名單、用途、跨境地區及依法需要的保障措施。

錢包地址、交易、餘額與持倉公開在區塊鏈，可能與其他身分資料連結；公開不代表可以不受限制地作任何後續用途。您自行選擇的外部 AI／MCP 平台、Operator、錢包及第三方協議另有資料流及政策，CRE8 仍須對自己選擇、傳送及整合的行為依法負責。

必要服務、安全與合規處理須按適用法律各自確定依據；可選持倉分享、分析或行銷用途須分開呈現，不預先勾選，不以其同意作為既有部位退出的前提。您可以不連接錢包閱讀文件；不啟用個人 Agent 或不送出訊息，不會觸發其模型任務。拒絕提供完成某項功能必要的資料，可能使該項功能無法提供。

六、保存、安全與權利

您可移除瀏覽器本機資料，但這不會刪除伺服器或公開鏈紀錄，也不撤銷已上鏈交易／allowance。移除待確認資料前，應先用原交易 hash 核對結果，避免重複提交。

正式服務應提供依法可行的查詢、閱覽、更正、停止處理、刪除、撤回可選同意及申訴管道，並說明適用的保存義務與例外。公開鏈通常不能由平台修改或刪除；對第三方獨立保存及備份亦不能承諾即時全部移除。

安全措施須與實際用途和風險相稱，仍不能保證絕無未授權存取。本稿不要求將身分證明、IP、私人聯絡或風險確認寫入公開鏈。
