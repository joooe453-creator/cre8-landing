# CRE8 使用前須知與法律聲明

版本：2026-10-07-draft.8｜狀態：未生效草稿

**請在建立金庫、存入資產或授權新增風險前，閱讀《使用條款》《金庫風險揭露》《使用資格與地區限制》，並查看該金庫的資產、費用、Operator 及退出條件。**

營運法人、註冊地與首批服務市場尚未確定。目前為未部署原型，沒有經核實、可接受正式入金的金庫；示例持倉與績效為模擬。本文件供閱讀、審閱及流程演練，不代表正式服務、收款或監管許可已開放。

## 1. 什麼時候會顯示風險提醒

完整法律文件放在 Docs 及頁腳，可自行另開、閱讀及保存。每次進入 Vaults 金庫列表、單一金庫或 Create 頁面時，各自動顯示一次針對投資人或建立者的英文提醒。進頁提醒提供風險全文連結、「Don't show this again」勾選框及「I understand the risks」按鈕，沒有「Close」或 X；不按「I understand the risks」即返回上一頁（沒有上一頁時回首頁）。不要求勾選三項條款／資格欄位，也不要求先閱讀全部文件才可繼續。

- **Vaults 金庫列表：** 每次訪問顯示一次「Before you explore vaults」／「For depositors」：本金可能全損、閱讀各金庫 Fund prospectus 的策略／費用／Agent 權限／退出，以及 Agent 依規則自主操作。
- **Create 建立頁面：** 每次訪問顯示一次「Before you create a vault」／「For vault creators」：核對資產／目的地／上限／費用、seed 本金及 Creator 最低持有風險，以及 Agent 審慎選擇、自主操作與替換 Operator 的治理延遲。
- **單一金庫：** 每次訪問顯示一次同一份投資人提醒，標題為「Before you deposit」，經連結直接進入也會看到；存款流程另詢問 Fund prospectus。以上提醒不須先連錢包，也不顯示本次操作摘要。
- **Don't show this again：** 勾選後再按「I understand the risks」，之後在同一瀏覽器以同一錢包（未連錢包時以此瀏覽器）進入相應頁面，不再自動顯示本版提醒，提醒版本更新後會再顯示。投資人提醒在列表與單一金庫共用，建立者及 CRE8 AI 提醒各自記錄。
- **存款閱讀提醒：** 每次發起存款／Safe 新入金流程，另問「Have you read the Fund prospectus?」，提供「Read prospectus」及「Yes, continue」。Read 只打開 Fund prospectus 供閱讀，停止該次流程、不簽名；讀完再按存款會重新詢問。X／Escape 取消，Yes 只繼續本次流程，不是正式條款同意、資格證明或交易完成。Create 操作不新增此問句。
- **本機存款預覽：** 「Preview transaction steps」也顯示閱讀問句，但僅為模擬，不開放正式入金。
- **本頁後續操作或變更：** Deposit、Create、Safe 操作、重試及金額／策略／錢包／網路變更不再觸發同一一般提醒。每次簽名仍須核對當次金額、地址、費用、授權及其他參數，不能以進頁提醒代替交易確認。
- **不繼續或重新進頁：** Escape 返回上一頁，不記為已了解風險或接受條款；按「I understand the risks」後本頁內不重跳；重新載入或離開後重新進入 Vaults、單一金庫或 Create 會再顯示一次，已對本版勾選「Don't show this again」者除外。
- **其他瀏覽與連接錢包：** 首頁、Docs／條款及單純錢包連接不因此自動跳此提醒；上述行為不授予 Agent 或資產移轉權限。
- **贖回或原資產退出：** 保留本次資產、費用、收款人、估計與流動性風險；不要求先接受新的商業條款或可選 AI 資料用途。依法限制的交易仍須另行處理。
- **個人 Agent 與 AI 點數：** 其資料分享、交付、價格與付款條件另按功能確認；金庫風險按鈕不接受這些獨立事項，也不表示相關正式流程已完成。

一般風險提醒的顯示狀態與按鈕確認結果分開，只暫存在目前頁面的記憶體；只有勾選「Don't show this again」並按「I understand the risks」時，才在本機 localStorage 記錄提醒 id、版本及最後在此連接的錢包地址（未連錢包時記為此瀏覽器），不上傳；換瀏覽器、裝置或清除網站資料後會再顯示。返回上一頁不是接受。這不是一般條款接受、地區聲明、KYC、制裁篩查、投資者資格或正式法律舉證。目前 `liveAllowed: false` 的獨立草稿限制仍拒絕正式建立／入金，按下「I understand the risks」或回答「Yes, continue」均不解除限制。

正式服務如依法需要明示同意、特定契約、資格資料、說明或審閱期間，必須另行完成；簡化提醒不表示一概不需條款同意。

## 2. 金庫、份額與 Agent

創作者選定金庫的資產、市場、NAV 上限及創作者績效費，並指定 Agent Operator。存入後，參與者取得自訂 MANDATE_FUND_V2 份額；它不宣稱完整 ERC-4626 相容，**份額不可轉讓**，不能依賴二級市場出售來退出。

份額反映合約定義的參與及比例退出機制；其法律分類仍按池化資產、管理、權利與適用法律判斷，不能只因名稱是 share、receipt、治理幣或 utility 就排除金融監管。

平台不要求您的私鑰或助記詞；MCP 提供未簽交易。資產存入金庫後，Operator 使用自己的簽名器在已核准範圍內自主操作，**持有人不會逐筆簽核後續交易**。您保管私鑰不代表金庫資產沒有受他人管理，也不消除服務提供者或 Operator 的法定責任。

Operator 身分本身沒有替持有人提款的特別權限。份額 allowance 可授權代理退出，代幣 allowance 用於轉入資產，須分別核對；撤銷 allowance 不會撤銷金庫對已存入資產的自主操作權。個別持有人無權更換整座金庫的 Operator；創作者可立即停用 Agent，輪替須等待至少 24 小時並符合啟用條件。

## 3. 使用資格與地區

目前尚未選定任何正式開放市場。草案擬將美國、加拿大與中國大陸列為暫不開放市場，人士定義及功能範圍仍待批准；這不是宣稱該等市場所有 DeFi 活動都全面違法，也不代表其他市場已核准。香港、澳門及台灣各自評估。

資格依本次功能、所在地／通常居住地、法人設立及營運地，以及依法必要的其他條件判斷。代表他人或法人時須有有效授權，實際資產所有人與受益對象亦須符合條件。受適用制裁、交易禁令及持有／控制規則限制的對象，不得接受被禁止的服務。

不得用虛假資料、VPN、代理、他人帳號或代持規避適用限制。能連接錢包、讀網站或直接呼叫公開合約，不代表取得服務資格。原型沒有完成身分核驗、IP 地區封鎖或制裁篩查；使用者風險確認不能取代平台及其他角色的許可、核驗與揭露義務。

## 4. 本金、估值與風控

**您可能損失全部投入資產。** 金庫沒有保本、固定收益、存款保險或隨時退出保證。價格、脫鉤、發行人／協議違約、合約、預言機、治理、流動性、MEV、網路與多協議依賴都可能導致損失。

NAV、份額價值、報價與年化數字不是保證成交或退出價格；歷史、模擬及第三方利率不保證扣費後報酬。公開程式碼、內部／fork 驗證、模擬及第三方審計不能保證安全；內部驗證不等於獨立審計。

至少 5% 閒置及投資上限在適用操作完成時檢查，市場變化可能改變其後比例，亦不保證流動性。Agent 虧損防護預設及平台上限為 5%，以 Agent 資本動作前後的正 NAV 損失記帳，25 個一小時桶涵蓋過去 24 小時並可能多保留最舊桶近一小時；**跨線動作先成交再停用 Agent，所以 5% 不是最大損失保證**。舊每日 2% 模型已不適用。

個人／逐資產止損、止盈及 trailing exit 有獨立規則；keeper、預言機、網路與市場故障可能使其不能及時或按目標價執行。借貸、槓桿或 NFT LP Position 另有負債、清算及無常損失等風險；尚未完成的 composite 多策略功能不視為可執行。

## 5. 費用與成本基礎

現行模型沒有管理費，另有：

| 費用 | 計算與限制 |
|---|---|
| 建立 | 創作者種子的 1%，基金上線時收一次；種子不另收存入費。 |
| 存入 | 固定 1%，依實際使用的總計價資產計算；原始單位向上取整，未用預算退回。 |
| 基金操作 | 不收（合約保留計費程序，費率與上限都是 0）。 |
| 退出績效 | 平台固定 10% 加創作者 0–20%，合計 10–30%，按本次退出相對該地址成本基礎的正收益計算。 |

每個持有地址按淨實際投入建立成本基礎；部分退出按份額比例分攤。計價資產退出按實際清算所得，可靠估值的原資產退出按本批實物估值分出費用；估值不可取得時豁免該筆無法計價的績效費。沒有整座金庫的未實現高水位、fee shares 或舊 90／10 分帳，也不通算跨錢包、跨金庫及所有歷次退出盈虧。

例如本次成本基礎 100、實際清算所得 120、創作者費率 10%：正收益 20，平台與創作者各收 2，淨交付 116；此例忽略捨入，100 不含最初已扣的存入費。網路、滑價、交易及底層協議成本另計。報價可能預留的 1% 可退執行緩衝不是額外固定費用。

建立費與存入費歸平台，平台與創作者亦有績效費利益，可能產生操作及推廣利益衝突。請核對具體金庫費率與收費地址。

## 6. 創作者投入、規則及退出

建立分為 prepare、deploy、finalize；finalize 才投入 100 計價資產單位並扣 1% 建立費。份額沒有固定時間鎖，但其他持有人仍在時，創作者必須保留至少流通份額的 2%；它限制創作者最大退出額，也可能限制後續存入。最後一位實際持有人可全數退出。

固定市場不能任意更換；提高 cap 須等待至少 24 小時，收緊可立即生效。創作者及 Risk Council 可依合約暫停部分活動，恢復亦可能有等待和條件；底層協議還有自己的治理與暫停權。

- **計價資產退出：** 處理退出者的比例持倉並交付計價代幣，例如 USDT，不是法定貨幣出金。實際所得須扣適用費用；最低收到額與期限應在簽名前核對。任何一腿失敗可能回滾整筆退出。
- **原資產退出：** 交付比例代幣、協議收據及閒置資產，可靠估值時另分出費用比例。後續兌換由持有人處理，不保證收據可轉移、有市場、即時贖回或兌回本金。

預言機、流動性、外部凍結、黑名單、資不抵債及 gas 條件可能妨礙退出；份額不可轉讓，亦沒有一般時間鎖，不代表可隨時取回本金。最後實際份額退出後，現行金庫永久關閉；最後持有人選計價資產退出時，可能另收到殘餘原資產／收據。

## 7. 簽名、授權與交易結果

一般風險確認、Fund prospectus 閱讀提醒、依法必要的條款接受、登入訊息、代幣 approval／Permit、份額 allowance、付款與送交易是不同事項。按下風險按鈕不移轉資產，也不表示鏈上交易已完成。

簽名前核對網路、合約、操作、金額、接收者、spender／額度、最低份額／收到額、nonce 及期限。既有大額 allowance 不會因這次輸入小額而自動減少。鏈上交易通常不可撤回，失敗仍可能支出 gas；結果不明先查原 hash，不要重複提交。

## 8. 個人 Agent、AI 點數及資料

個人 Agent 的鏈下聊天／方案與金庫 Operator 不同，模型不持有提款權，鏈上建立仍需另行錢包確認。示意手機預覽不呼叫 AI、不收款或送交易；正式功能以實際開放配置為準。

對話、任務、登入、模型用量、點數及付款紀錄可保存於伺服器資料庫。現行正式模型路徑是 Anthropic Claude，任務必要內容與近期對話可傳送給模型；不能把原型所有資料說成只存在本機。可選持倉分享預設關閉，啟用後查詢已審核資產，提供約略持倉摘要；RPC 仍需地址，使用者自行輸入也可能含身分。

AI 輸出可能錯誤、過期或不適合您；不得只依其輸出交易。支付任務或點數不保證策略、安全、獲利或持續執行，也不增加金庫權限。價格、點數扣除、交付、修改及退款須在功能確認中另揭露，與金庫費用分開。

每次進入 CRE8 AI 對話頁面時，會顯示一次英文提醒：AI 回答可能錯誤、不完整或過時，即使語氣自信亦須自行核對策略、費用、地址與交易資料。只有「Got it」可繼續，沒有 X；Escape 返回上一頁。本頁內打字、切換任務或繼續對話不重跳；勾選「Don't show this again」再按「Got it」後，同一瀏覽器的同一錢包不再自動顯示；輸入框下持續顯示「AI can make mistakes. Verify important information before acting.」。AI 提醒亦出現在介面預覽，該預覽仍只有固定示例，沒有呼叫模型或收款。按「Got it」不是法律同意、付款授權或持倉分享同意。

頁面一般風險提醒的顯示狀態及按鈕確認結果僅在本頁記憶體暫存，「Don't show this again」只存在本機瀏覽器，均不上傳；個人 Agent 歷史另按伺服器機制保存。清除歷史不等於立即刪除所有付款、任務與備份資料。公開鏈紀錄通常不能由平台刪除；請閱讀《隱私告知》的實際資料流及保存差異。
