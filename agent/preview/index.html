FROM IDEA TO VAULT

整個流程，你都能看清楚。

個人 Agent 在鏈下協助探索與設計；資金操作由錢包確認，金庫規則在鏈上執行。

  1. 01

    連接錢包，建立工作空間

    正式服務以限定用途的登入簽名辨識你，保存個人 Agent 與任務紀錄。Agent 不持有你的私鑰。

  2. 02

    先免費探索

    告訴 Agent 想找什麼金庫、使用哪些資產。探索只在平台提供的範圍內進行，額度由平台設定。

  3. 03

    確認完整任務報價

    比較、設計或檢查策略會先列出固定任務費、交付內容、修改次數與期限。查看進度不另收費。

  4. 04

    付款核對後，產出方案

    正式服務確認付款後才啟動 OpenAI。AI 依核准的資產與配置產出方案，付款不擴大資金操作權限。

  5. 05

    審閱，再選擇金庫

    現有金庫可查看規則與費用後存入；自己的金庫則需確認配置上限、費用、執行 Agent、seed 與最低 2% 持有要求。

  6. 06

    另外確認鏈上交易

    金庫建立依序完成預備、部署與啟用；必要授權另行確認。任務費、gas 與金庫費用分開呈現。

  7. 07

    按規則持續執行

    執行 Agent／keeper 按批准的規則操作，仍需監控與維護。存入、退出與權限管理可直接使用，不依賴 AI 額度。

這個分享頁展示的是未部署的介面示例。所有對話、5 次額度與 TEST 報價均為示意；沒有真實 AI、付款或金庫交易。
